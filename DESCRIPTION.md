# Система управления Docker-инфраструктурой

## 1. Ядро системы

### Аутентификация и авторизация

* Регистрация / вход пользователей (JWT).
* Группы пользователей (команды) с наследованием прав.
* Гибкая RBAC-модель:

    * создание контейнеров;
    * просмотр логов;
    * управление секретами;
    * редактирование proxy-правил;
    * управление сетями и volumes;
    * деплой приложений.
* Разграничение доступа по проектам:

    * каждый контейнер или группа контейнеров принадлежит проекту;
    * права доступа настраиваются отдельно.

### Аудит действий

Логирование всех действий пользователей:

* кто выполнил действие;
* над каким объектом;
* когда;
* результат операции.

Примеры:

* запуск / остановка контейнера;
* изменение proxy-конфига;
* выпуск сертификата;
* изменение секретов;
* деплой приложения.

## Контейнеры

### Управление контейнерами

## Процесс деплоя

1. Пользователь:

    * загружает артефакт;
    * либо указывает Git-репозиторий.
2. Система:

    * запускает build container;
    * выполняет сборку.
3. Генерируется Docker image.
4. Image тегируется.
5. Image сохраняется в registry.
6. Контейнер запускается.
